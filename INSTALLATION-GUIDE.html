一、简介与版本对比

本工具用于将 AI（如 ChatGPT、Claude、DeepSeek 等）回复的 Markdown 内容，一键转换为带格式的富文本，粘贴到 Microsoft Word 后标题层级、加粗、斜体、列表、表格、代码块、引用等样式完整保留。

版本文件适用场景安装要求
网页版 markdown-word 转换器.html 临时使用、不想安装任何软件 仅需浏览器
便携版 Markdown-Word 转换器-绿色版.zip 免安装、解压即用 Windows 10/11
安装版 Markdown-Word转换器 Setup 1.0.0.exe 长期使用、需要桌面快捷方式 Windows 10/11
核心原理

普通复制只能得到纯文本，格式会丢失。本工具将 Markdown 解析为 HTML 后，通过系统剪贴板写入 text/html 富文本格式。Word 识别该格式并还原样式。桌面版使用 Electron 原生剪贴板 API，格式还原比网页版更可靠。

二、网页版使用

步骤

  1. 双击 markdown-word 转换器.html，用浏览器打开
  2. 将 AI 回复的 Markdown 内容粘贴到左侧输入框
  3. 右侧自动实时预览转换效果
  4. 点击「复制富文本」按钮，或按 Ctrl+Shift+C
  5. 打开 Word，按 Ctrl+V 粘贴，格式完整保留
提示

网页版无需安装、离线可用（首次打开后浏览器会缓存），适合临时场景。但部分浏览器可能限制剪贴板写入 HTML，如复制后 Word 中格式不全，请使用桌面版。

三、桌面版 · 绿色便携版

安装步骤

  1. 获取 Markdown-Word 转换器-绿色版.zip 压缩包
  2. 右键 →「全部解压缩」，解压到任意目录（如桌面或 D:\Apps\）
  3. 进入解压后的文件夹
  4. 双击 Markdown-WordConverter.exe 即可启动
优势

免安装、不写注册表、不生成系统垃圾，可放入 U 盘随身携带。删除时直接删掉整个文件夹即可。

四、桌面版 · 安装程序

安装步骤

  1. 双击运行 Markdown-Word转换器 Setup 1.0.0.exe
  2. 如出现 Windows SmartScreen 提示，点击「更多信息」→「仍要运行」（应用未签名，属正常）
  3. 选择安装路径（默认 %LOCALAPPDATA%\Programs\ 下），点击「下一步」
  4. 选择是否创建桌面快捷方式和开始菜单快捷方式
  5. 点击「安装」，等待数秒完成
  6. 点击「完成」退出安装向导

卸载方式

  • 方式一：开始菜单 → 找到「Markdown-Word转换器」→ 右键 → 卸载
  • 方式二：设置 → 应用 → 已安装的应用 → 搜索「Markdown-Word」→ 卸载
  • 方式三：安装目录下运行 Uninstall Markdown-WordConverter.exe

五、从源码构建

环境要求

  • Node.js v18+（推荐 v22）
  • npm v10+
  • Windows 10/11（打包目标）

步骤

# 1. 进入项目目录
cd markdown-word-desktop

# 2. 安装依赖
npm install

# 3. 开发模式运行（调试用）
npm start

# 4. 打包为安装程序（需管理员权限）
npx electron-builder --win

# 5. 产物在 release/ 目录
#    - win-unpacked\         未打包的应用目录（可直接运行）
#    - ...Setup 1.0.0.exe    NSIS 安装程序
注意

打包安装程序时，electron-builder 需要创建符号链接，这要求当前账户有 SeCreateSymbolicLink 权限。如果当前账户为「过滤管理员」，请以管理员身份运行 build-installer.cmd，或开启 Windows「开发者模式」。

六、使用教程

基本操作

  1. 启动应用（或打开网页版）
  2. 在 AI 对话窗口中复制回复的 Markdown 文本
  3. 在转换器左侧输入框粘贴（Ctrl+V）
  4. 右侧实时显示格式预览，确认效果
  5. 选择输出方式：
    • 复制富文本：点击按钮 → 切换到 Word → Ctrl+V 粘贴
    • 导出 Word 文档：点击按钮 → 选择保存位置 → 直接生成 .doc 文件
导出 Word 文档

点击工具栏「导出 Word 文档」按钮，可直接生成 .doc 文件保存到本地，无需手动复制粘贴。桌面版弹出系统保存对话框让你选择路径；网页版则由浏览器直接下载。文件名自动从 Markdown 首个标题提取，无标题时默认为「导出文档」。

快捷键
  • Ctrl+Shift+C — 复制富文本（最常用）

七、常见问题

Q1：粘贴到 Word 后格式丢失了？

A：请确认使用的是「复制富文本」按钮而非「复制纯文本」。若使用网页版仍丢失，可能是浏览器限制了 HTML 剪贴板写入，请改用桌面版（Electron 原生剪贴板更可靠）。在 Word 中粘贴时，若出现粘贴选项按钮，选择「保留源格式」。

Q2：安装程序被杀毒软件拦截？

A：本应用未做代码签名，部分杀毒软件会对未签名的安装包发出警告。这是正常现象，可以放心放行。如需彻底避免，需购买代码签名证书（成本较高，个人工具通常不做）。

Q3：Windows SmartScreen 提示"已保护你的电脑"？

A：点击「更多信息」→「仍要运行」即可。这是因为应用没有数字签名，Windows 对未签名程序的默认安全提示，不影响使用。

Q4：打包时提示"Cannot create symbolic link"？

A：这是因为当前账户没有创建符号链接的权限。解决方案：① 右键 build-installer.cmd → 以管理员身份运行；② 或在 Windows 设置中开启「开发者模式」（设置 → 隐私和安全性 → 开发者选项）。

Q5：代码块在 Word 里背景颜色不对？

A：Word 对深色背景的 HTML 渲染支持有限。代码块会显示为浅灰背景或等宽字体，不影响内容可读性。如需精确还原深色效果，建议在 Word 中手动套用代码样式。

Q6：能否支持 macOS 或 Linux？

A：当前打包仅针对 Windows。项目基于 Electron 跨平台架构，修改 package.json 中的 build.win.target 并执行 npx electron-builder --mac 或 --linux 即可生成对应平台安装包。
