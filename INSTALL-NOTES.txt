================================================================================
  Markdown → Word 转换器  ·  安装与使用说明
  版本：v1.4.0  |  系统要求：Windows 10 / 11
================================================================================

【一、这是什么？】
本工具用于将 AI（ChatGPT、Claude、DeepSeek 等）回复的 Markdown 内容，
一键转换为带格式的富文本，粘贴到 Microsoft Word 后，标题、加粗、列表、
表格、代码块、引用等样式完整保留。还支持直接导出 .docx（原生格式）、
.doc（兼容格式）Word 文档与 .tex（LaTeX）源码，并支持把文件拖进窗口
自动识别类型、反向转换为 Markdown。

--------------------------------------------------------------------------------
【二、本仓库包含什么？】
  main.js                            桌面版主进程（窗口、原生剪贴板、打开/保存对话框）
  preload.js                         预加载脚本（向渲染进程暴露桌面 API）
  renderer/index.html                桌面版界面与 Markdown 解析
  renderer/docxgen.js                零依赖 .docx（OOXML）生成器
  renderer/texconv.js                Markdown ↔ LaTeX 双向转换（含数学公式解析）
  renderer/docxread.js               零依赖 .docx/.doc 读取与反向转换
  web/markdown-word-converter.html   网页版单文件，双击即用
  tests/                             自动化测试（node --test 运行）
  build/icon.ico / build/icon.png    应用图标
  build-ico.js                       图标生成脚本
  build-installer.cmd                一键打包 Windows 安装程序
  package.json                       依赖与打包配置
  INSTALLATION-GUIDE.html            图文安装指南
  INSTALL-NOTES.txt                  本说明（TXT 版）
--------------------------------------------------------------------------------

【三、如何使用？】
----------------------------------------------------------------------
方式一：网页版 · 免安装（最快）
----------------------------------------------------------------------
  1. 下载本仓库中的 web/markdown-word-converter.html；
  2. 双击该文件，浏览器会打开它；
  3. 把 AI 回复的 Markdown 粘贴到左侧输入框，右侧实时预览；
  4. 点「复制富文本」，切换到 Word 按 Ctrl+V 粘贴（格式完整保留）；
     或选好导出格式后点「导出文档」，由浏览器直接下载文件。

----------------------------------------------------------------------
方式二：桌面版 · 从源码运行（推荐，原生剪贴板最可靠）
----------------------------------------------------------------------
  需要先安装 Node.js（v18 及以上）与 npm。
  1. 克隆或下载本仓库到本地；
  2. 打开命令提示符，进入仓库目录；
  3. 执行：  npm install
  4. 开发运行：  npm start
  5. 打包为 Windows 安装程序（NSIS）：
        build-installer.cmd
     或：  npx electron-builder --win
     （打包过程会创建符号链接，若当前账户权限不足，请以管理员身份运行）
  6. 产物位于 release 目录，安装程序为「... Setup x.y.z.exe」，
     解压后的免安装版本在 release/win-unpacked。
--------------------------------------------------------------------------------

【四、使用方法】
  1. 启动桌面程序（或打开网页版）；
  2. 在 AI 对话窗口复制回复的 Markdown 文本；
  3. 粘贴（Ctrl+V）到转换器左侧输入框；
  4. 右侧实时预览转换效果；
  5. 在工具栏右侧下拉框选择导出格式（.docx / .doc / .tex，默认 .docx）；
  6. 选择输出方式：
        a) 复制富文本：点「复制富文本」按钮（或按 Ctrl+Shift+C），
           切换到 Word，按 Ctrl+V 粘贴，格式完整保留；
        b) 导出文档：点「导出文档」按钮，选择保存位置，
           桌面版弹系统保存框，网页版由浏览器下载。

  【拖入文件自动识别】
  把 .md / .txt / .tex / .docx / .doc 文件直接拖进窗口，或点「导入文件」
  按钮选择，程序会按扩展名 + 内容特征判断输入类型，并按「类型互补」
  规则自动切换导出格式：
       拖入 .md / .txt / .docx / .doc  →  自动选 .tex
       拖入 .tex                        →  自动选 .docx
  识别结果只改下拉框默认值，仍可手动切换。
  拖入 .docx 会自动反向解析为 Markdown（含标题、列表、表格、超链接与公式）。
  旧版二进制 .doc（OLE 复合文档）暂不支持直接解析，请先在 Word 中
  「另存为」.docx 后再拖入；本工具自己导出的 HTML 形态 .doc 可直接拖入。

【五、支持的 Markdown 元素】
  标题          # 一级    ## 二级    ### 三级
  加粗          **文字**
  斜体          *文字*
  删除线        ~~文字~~
  无序列表      - 项目
  有序列表      1. 项目（支持缩进嵌套，最多 9 级）
  引用          > 引用文字
  代码块        ```语言 ...```
  行内代码      `代码`
  表格          | 列1 | 列2 |  (第二行用 --- 作分隔线)
  链接          [文字](URL)
  分割线        ---
  数学公式      $x^2$  /  $$..$$（预览为 MathML，导出 .docx 为 Word 原生公式）
--------------------------------------------------------------------------------

【六、导出格式说明】
  .docx  按 OOXML 规范打包（ZIP + WordprocessingML），零依赖、离线可用。
         Word 2007+ 与 WPS 均可正常打开与编辑；标题进入 Word 内置标题样式，
         可在导航窗格与自动目录中使用。默认推荐。
  .doc   HTML 内容封装为 .doc，Word 可打开，本质仍是 HTML，仅极旧环境兼容。
  .tex   Markdown 映射为 LaTeX 命令，中文默认走 ctexart 文档类，
         可直接用 xelatex 编译为 PDF。

【七、常见问题】
  Q1. 粘贴到 Word 后格式丢失？
       确认用的是「复制富文本」而非「复制纯文本」。若用网页版仍丢失，
       可能是浏览器限制了剪贴板写入，请改用桌面版（原生剪贴板更可靠）。
       在 Word 中粘贴时，若出现粘贴选项，选「保留源格式」。

  Q2. 杀毒软件或 SmartScreen 拦截？
       本工具未做代码签名，未签名程序会触发系统安全提示，属正常现象，
       可放心放行（点击「更多信息」→「仍要运行」）。

  Q3. 打包报 "Cannot create symbolic link"？
       当前账户缺少创建符号链接的权限。解决：右键 build-installer.cmd
       以管理员身份运行，或在 Windows 设置中开启「开发者模式」。

  Q4. 导出的 .docx 打不开？
       请使用 v1.2.1 及以上版本，旧版本在内容含特殊控制字符时可能生成
       损坏的文档，该问题已在本版本修复。

  Q5. 拖入 .doc 提示无法解析？
       旧版二进制 .doc 是 OLE 复合文档，本工具不解析。请在 Word 中打开该
       文件，「另存为」.docx 后再拖入。本工具导出的 HTML 形态 .doc 可直接拖入。

  Q6. 拖入文件后导出格式为什么变了？
       这是「类型互补」推荐：拖入 Markdown / Word 类文件自动选 .tex，
       拖入 LaTeX 文件自动选 .docx，避免转回原格式。仍可手动改。

  Q7. 能支持 Mac 或 Linux 吗？
       项目基于 Electron 跨平台，修改 package.json 的打包目标后可生成
       对应平台安装包。
