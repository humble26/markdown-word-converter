  Markdown → Word 转换器  ·  安装与使用说明（TXT 版）
  版本：v1.1.0  |  系统要求：Windows 10 / 11
================================================================================

【一、这是什么？】
本工具用于将 AI（ChatGPT、Claude、DeepSeek 等）回复的 Markdown 内容，
一键转换为带格式的富文本，粘贴到 Microsoft Word 后，标题、加粗、列表、
表格、代码块、引用等样式完整保留。还支持直接导出 .doc Word 文档文件。

--------------------------------------------------------------------------------
【二、本文件夹包含什么？】
  01-Desktop-Portable/   桌面程序（推荐），免安装，解压/复制即可用
  02-Web-NoInstall/      单文件网页版，双击用浏览器打开即可
  03-Source-Desktop/     桌面版程序源码（供开发者）
  04-Source-Web/         网页版源码（供开发者）
  05-Assets-Icons/       应用图标文件
  06-Docs/               本文档与更详细的安装指南（HTML 版）
--------------------------------------------------------------------------------

【三、如何安装？（按需选择一种即可）】
----------------------------------------------------------------------
方式一：桌面版 · 绿色便携版（推荐，无需安装）
----------------------------------------------------------------------
  1. 进入「01-Desktop-Portable」文件夹；
  2. 双击「Markdown-WordConverter.exe」即可运行；
  3. 如需移动到其他位置，直接把整个文件夹复制/剪切到目标位置即可，
     无需重新安装，不写注册表。

----------------------------------------------------------------------
方式二：网页版 · 免安装
----------------------------------------------------------------------
  1. 进入「02-Web-NoInstall」文件夹；
  2. 双击「markdown-word-converter.html」，浏览器会打开它；
  3. 直接使用，无需任何安装步骤。

----------------------------------------------------------------------
方式三：从源码自行打包（供开发者）
----------------------------------------------------------------------
  需要先安装 Node.js（v18 及以上）与 npm。
  1. 将「03-Source-Desktop」整个文件夹复制到工作目录；
  2. 打开命令提示符，进入该目录；
  3. 执行：  npm install
  4. 开发运行：  npm start
  5. 打包为 Windows 安装程序（NSIS）：
        npx electron-builder --win
     （打包过程会创建符号链接，若当前账户权限不足，请以管理员身份运行，
       或让 build-installer.cmd 以管理员身份运行）
  6. 产物位于 release 目录，解开压缩后的应用在 release/win-unpacked。
--------------------------------------------------------------------------------

【四、使用方法】
  1. 启动桌面程序（或打开网页版）；
  2. 在 AI 对话窗口复制回复的 Markdown 文本；
  3. 粘贴（Ctrl+V）到转换器左侧输入框；
  4. 右侧实时预览转换效果；
  5. 选择输出方式：
        a) 复制富文本：点「复制富文本」按钮（或按 Ctrl+Shift+C），
           切换到 Word，按 Ctrl+V 粘贴，格式完整保留；
        b) 导出 Word：点「导出 Word 文档」按钮，选择保存位置，
           直接生成 .doc 文件，桌面版弹系统保存框，网页版由浏览器下载。
  6. 完成。

--------------------------------------------------------------------------------
【五、支持的 Markdown 元素】
  标题          # 一级    ## 二级    ### 三级
  加粗          **文字**
  斜体          *文字*
  删除线        ~~文字~~
  无序列表      - 项目
  有序列表      1. 项目
  引用          > 引用文字
  代码块        ```语言 ...```
  行内代码      `代码`
  表格          | 列1 | 列2 |  (第二行用 --- 作分隔线)
  链接          [文字](URL)
  分割线        ---

【六、常见问题】
  Q1. 粘贴到 Word 后格式丢失？
       确认用的是「复制富文本」而非「复制纯文本」。若用网页版仍丢失，
       可能是浏览器限制了剪贴板写入，请改用桌面版（原生剪贴板更可靠）。
       在 Word 中粘贴时，若出现粘贴选项，选「保留源格式」。

  Q2. 杀毒软件或 SmartScreen 拦截？
       本工具未做代码签名，未签名程序会触发系统安全提示，属正常现象，
       可放心放行（点击「更多信息」→「仍要运行」）。

  Q3. 打包报 "Cannot create symbolic link"？
       当前账户缺少创建符号链接的权限。解决：右键 build-installer.cmd
       以管理员身份运行，或在 Windows 设置中开启「开发者模式」。

  Q4. 能支持 Mac 或 Linux 吗？
       项目基于 Electron 跨平台，修改 package.json 的打包目标后可生成
       对应平台安装包。
